=== serveri baslatmak icin:
> > node server.js

=== server kapatmak icin: 
> > CTRL C

=== Server arkaplanda surekli kalmasi icin:
>>> npm install -g pm2 (bi kere yapilsa yeter. suan yapildi zaten bunu gecmeyi dene)
>>> pm2 start npm --name "my-app" -- start
>>> pm2 startup    (pc yeniden baslasa bile serveri oto baslatmasi icin)


=== Acik serverlari listelemek icin: 
>>> lsof -i :3000


=== Spesific oto server kapatmak icin: (my-app serveri bu ornek icin)
>>> pm2 stop my-app   # Durdur


=== Tum serverleri kapatmak icin:
>>> kill -9 94369 (94369 bu numara P id. bunu serverleri listeleyince goreceksin.)
